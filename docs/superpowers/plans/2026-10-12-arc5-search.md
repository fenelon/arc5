# arc5 Search (Milestone 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every archived message is full-text searchable by word form in the owner's languages, with phrases, prefixes, filters, ranking and highlighted snippets, and the index rebuilds itself when its analyzer changes.

**Architecture:** A new `internal/search` package owns text analysis (normalizing, stemming, character pairs for scripts without spaces), query parsing, query execution and snippets. The archive stays the only writer: it calls the analyzer inside `UpsertMessage`'s transaction and writes the two columns of a contentless FTS5 table. `search` reads through the archive's read-only pool.

**Tech Stack:** Go 1.26, `modernc.org/sqlite` (FTS5), `github.com/blevesearch/snowballstem` v0.9.0, `golang.org/x/text/unicode/norm`.

**Spec:** `docs/superpowers/specs/2026-10-12-message-archive-design.md` (section 5, and `arc5 reindex` in section 9). This is milestone 2 of the five in section 12.

## Global Constraints

- Module path `github.com/fenelon/arc5`; no cgo.
- `internal/archive` is the only package that writes to the database. `internal/search` reads through `Store.Reader()`.
- The index is derived data: `messages_fts` is a contentless FTS5 table (`content=''`, `contentless_delete=1`, `tokenize='ascii'`) with columns `exact` and `stem`, keyed by `messages.id`.
- Every token the analyzer emits contains only letters, numbers and combining marks, so the `ascii` tokenizer splits on nothing but the spaces between tokens.
- Query terms are ANDed. A quoted phrase matches `exact` only. The last unquoted word matches as a prefix unless the query ends with a space.
- Ranking is `bm25(messages_fts, 2.0, 1.0)`: `exact` weighs twice `stem`.
- Default language list is `en`. Default page size is 50 hits.
- Stemming languages: ar, da, de, en, es, fi, fr, ga, hu, it, nl, no, pt, ro, ru, sv, ta, tr.
- Every task ends with `go vet ./... && go test -race ./...` passing.

## Facts verified before writing this plan

These were checked against the bundled SQLite (3.53.4) and the stemming library in a throwaway program, so the plan's code relies on them:

- `INSERT OR REPLACE` and `DELETE` work on a `contentless_delete=1` table, and `INSERT INTO t(t) VALUES('delete-all')` empties it.
- The `ascii` tokenizer keeps every non-ASCII character as part of a token (Cyrillic, accented Latin and CJK all match exactly) and does not fold accents.
- `exact:"word"`, `stem:"word"`, `exact:"word"*`, `exact:"two words"`, `(a OR b)` and `(…) AND (…)` all parse; `bm25(messages_fts, 2.0, 1.0)` works in `ORDER BY` with the FTS table joined to another table.
- Stems: `cats`→`cat`, `running`→`run`; `собаки`, `собака`, `собаку`→`собак`; `canciones`, `canción`→`cancion`. The Russian stemmer leaves `ё` alone, so `ё` must become `е` first.
- Two `Store`s on one folder fail with `SQLITE_BUSY` on 160 of 200 writes today, and on none with `_txlock=immediate`.

## Review Focus

1. **Hostile or odd queries.** Unbalanced quotes, FTS5 operators and syntax (`AND`, `NEAR(`, `exact:`, `*`, parentheses), punctuation only, and several thousand pasted words must return a result, never an SQL or syntax error. Pinned in Task 7.
2. **Odd text.** Emoji with modifiers and joiners, combining marks, invalid UTF-8 and mixed scripts must index and produce snippets without a panic and without splitting a character. Pinned in Tasks 3 and 6.
3. **A stale index.** After the language list changes, or a rebuild is interrupted, the index must be reported as not current so it is rebuilt. Pinned in Tasks 4 and 8.
4. **Ingestion during a rebuild.** Messages that arrive while the index is being rebuilt must be searchable afterwards. Pinned in Task 4.
5. **Edits and deletions.** An edited message is found by its new text and not its old; a message deleted at the source stays searchable. Pinned in Tasks 4 and 7.

```go
// Package search turns text into index terms, parses queries, and runs them
// against the archive's full-text index.
package search

import (
	"strings"
	"unicode"

	"golang.org/x/text/unicode/norm"
)

// normalizeWord prepares a word for stemming. Compatibility forms are unified
// and case is dropped. ё becomes е: Russian treats them as one letter, and so
// does its stemmer. Anything that is not a letter, number or mark, which
// normalization can introduce, is removed.
func normalizeWord(raw string) string {
	var b strings.Builder
	for _, r := range strings.ToLower(norm.NFKC.String(raw)) {
		switch {
		case r == 'ё':
			b.WriteRune('е')
		case unicode.IsLetter(r), unicode.IsNumber(r), unicode.IsMark(r):
			b.WriteRune(r)
		}
	}
	return b.String()
}

// fold removes accents from Latin and Greek letters, so "creme" finds
// "crème". Other scripts are left alone: their marks carry meaning, and й is
// not an accented и.
func fold(s string) string {
	var b strings.Builder
	foldable := false
	for _, r := range norm.NFD.String(s) {
		if foldable && r >= 0x0300 && r <= 0x036F {
			continue
		}
		foldable = unicode.In(r, unicode.Latin, unicode.Greek)
		b.WriteRune(r)
	}
	return norm.NFC.String(b.String())
}
```

// Language is a language whose word forms the analyzer can reduce to a stem.
type Language struct {

	Name string

	script *unicode.RangeTable
	stem   func(*snowballstem.Env) bool
}

// languages is sorted by code.
var languages = []Language{

	{"da", "Danish", unicode.Latin, danish.Stem},
	{"de", "German", unicode.Latin, german.Stem},
	{"en", "English", unicode.Latin, english.Stem},
	{"es", "Spanish", unicode.Latin, spanish.Stem},
	{"fi", "Finnish", unicode.Latin, finnish.Stem},
	{"fr", "French", unicode.Latin, french.Stem},
	{"ga", "Irish", unicode.Latin, irish.Stem},
	{"hu", "Hungarian", unicode.Latin, hungarian.Stem},
	{"it", "Italian", unicode.Latin, italian.Stem},
	{"nl", "Dutch", unicode.Latin, dutch.Stem},
	{"no", "Norwegian", unicode.Latin, norwegian.Stem},
	{"pt", "Portuguese", unicode.Latin, portuguese.Stem},
	{"ro", "Romanian", unicode.Latin, romanian.Stem},
	{"ru", "Russian", unicode.Cyrillic, russian.Stem},
	{"sv", "Swedish", unicode.Latin, swedish.Stem},
	{"ta", "Tamil", unicode.Tamil, tamil.Stem},
	{"tr", "Turkish", unicode.Latin, turkish.Stem},
}

// Languages lists every language stemming is available for, sorted by code.
func Languages() []Language { return slices.Clone(languages) }

// DefaultLanguages is the language list used until the owner chooses one.
const DefaultLanguages = "en"

// ParseLanguages splits a comma-separated setting such as "en, ru,es".
func ParseLanguages(setting string) []string {
	var codes []string
	for _, c := range strings.Split(setting, ",") {
		if c = strings.ToLower(strings.TrimSpace(c)); c != "" {
			codes = append(codes, c)
		}
	}
	return codes
}

const (
	// analyzerVersion changes whenever analysis changes in a way that makes
	// an existing index wrong, which forces a rebuild.
	analyzerVersion = "v1"
	// maxStemBytes keeps stemmers away from tokens that are not words, such
	// as pasted keys and hashes.
	maxStemBytes = 64
)

// Analyzer turns text into index terms for a chosen set of languages.
type Analyzer struct {
	langs []Language // sorted by code, no duplicates
}

// NewAnalyzer returns an analyzer that stems the given languages. With no
// languages it still finds exact words, prefixes and phrases.
func NewAnalyzer(codes []string) (*Analyzer, error) {
	a := &Analyzer{}
	for _, code := range codes {
		if slices.ContainsFunc(a.langs, func(l Language) bool { return l.Code == code }) {
			continue
		}
		i := slices.IndexFunc(languages, func(l Language) bool { return l.Code == code })
		if i < 0 {
			known := make([]string, len(languages))
			for k, l := range languages {
				known[k] = l.Code
			}
			return nil, fmt.Errorf("unknown search language %q; available: %s", code, strings.Join(known, ", "))
		}
		a.langs = append(a.langs, languages[i])
	}
	sort.Slice(a.langs, func(i, j int) bool { return a.langs[i].Code < a.langs[j].Code })
	return a, nil
}

// Languages returns the configured language codes, sorted.
func (a *Analyzer) Languages() []string {
	codes := make([]string, len(a.langs))
	for i, l := range a.langs {
		codes[i] = l.Code
	}
	return codes
}

// Signature identifies this analysis. An index built under another signature is stale.
func (a *Analyzer) Signature() string {
	return analyzerVersion + ":" + strings.Join(a.Languages(), ",")
}

// stems returns the distinct stems of a normalized word under every
// configured language written in the word's script, accents folded.
func (a *Analyzer) stems(word string) []string {
	if len(word) > maxStemBytes {
		return nil
	}
	first, _ := utf8.DecodeRuneInString(word)
	var out []string
	for _, lang := range a.langs {
		if !unicode.Is(lang.script, first) {
			continue
		}
		if s := fold(runStemmer(lang, word)); s != "" && !slices.Contains(out, s) {
			out = append(out, s)
		}
	}
	return out
}

// runStemmer returns "" if the stemmer panics: it is generated code run on
// arbitrary text, and one bad word must not stop a message being stored.
func runStemmer(lang Language, word string) (stem string) {
	defer func() {
		if recover() != nil {
			stem = ""
		}
	}()
	env := snowballstem.NewEnv(word)
	lang.stem(env)
	return env.Current()
}

package search

import (
	"strings"
	"unicode"
	"unicode/utf8"
)

// Token is one searchable unit of a text.
type Token struct {
	Start, End int      // byte offsets of the token in the original text
	Exact      string   // normalized form, as stored in the index's exact column
	Stems      []string // stemmed forms; nil when no configured language applies
	Gram       bool     // a character pair from a script written without spaces
}

// unspaced reports whether r belongs to a script written without spaces
// between words. Such text is indexed as overlapping character pairs, because
// there are no word boundaries to find. ー is the Japanese long-vowel mark,
// which Unicode files under no script.
func unspaced(r rune) bool {
	return r == 'ー' || unicode.In(r, unicode.Han, unicode.Hiragana, unicode.Katakana,
		unicode.Thai, unicode.Lao, unicode.Khmer, unicode.Myanmar)
}

func wordStart(r rune) bool { return unicode.IsLetter(r) || unicode.IsNumber(r) }

// Tokens splits text into index terms.
func (a *Analyzer) Tokens(text string) []Token {
	var out []Token
	for i := 0; i < len(text); {
		r, size := utf8.DecodeRuneInString(text[i:])
		switch {
		case unspaced(r):
			end := i + size
			for end < len(text) {
				r, size := utf8.DecodeRuneInString(text[end:])
				if !unspaced(r) {
					break
				}
				end += size
			}
			out = appendPairs(out, text, i, end)
			i = end
		case wordStart(r):
			end := i + size
			for end < len(text) {
				r, size := utf8.DecodeRuneInString(text[end:])
				if unspaced(r) || !(wordStart(r) || unicode.IsMark(r)) {
					break
				}
				end += size
			}
			if word := normalizeWord(text[i:end]); word != "" {
				if exact := fold(word); exact != "" {
					out = append(out, Token{Start: i, End: end, Exact: exact, Stems: a.stems(word)})
				}
			}
			i = end
		default:
			i += size
		}
	}
	return out
}

// appendPairs adds the overlapping character pairs of text[start:end], or the
// single character if there is only one.
func appendPairs(out []Token, text string, start, end int) []Token {
	type char struct {
		start, end int
		form       string
	}
	var chars []char
	for i := start; i < end; {
		_, size := utf8.DecodeRuneInString(text[i:])
		if form := normalizeWord(text[i : i+size]); form != "" {
			chars = append(chars, char{i, i + size, form})
		}
		i += size
	}
	if len(chars) == 1 {
		return append(out, Token{Start: chars[0].start, End: chars[0].end, Exact: chars[0].form, Gram: true})
	}
	for k := 0; k+1 < len(chars); k++ {
		out = append(out, Token{Start: chars[k].start, End: chars[k+1].end, Exact: chars[k].form + chars[k+1].form, Gram: true})
	}
	return out
}

// Index returns the text of the index's two columns for a document: tokens
// separated by single spaces. With Signature it implements archive.Analyzer.
func (a *Analyzer) Index(text string) (exact, stem string) {
	var e, s strings.Builder
	for _, t := range a.Tokens(text) {
		e.WriteString(t.Exact)
		e.WriteByte(' ')
		for _, form := range t.Stems {
			s.WriteString(form)
			s.WriteByte(' ')
		}
	}
	return e.String(), s.String()
}

package archive

import (
	"context"
	"database/sql"
	"errors"
	"strings"
)

// Analyzer turns text into the two columns of the search index. Package
// search implements it; the archive only stores what it returns, so the
// archive stays the only writer.
type Analyzer interface {
	// Index returns space-separated terms for the exact and stem columns.
	Index(text string) (exact, stem string)
	// Signature identifies the analysis. An index built under another signature is stale.
	Signature() string
}

// ErrNoAnalyzer is returned by Reindex when SetAnalyzer has not been called.
var ErrNoAnalyzer = errors.New("no search analyzer is set")

const indexSignatureKey = "search_index_signature"

// reindexBatch is how many messages Reindex indexes per transaction, so that
// ingestion is never blocked for long. It is a variable so tests can shrink it.
var reindexBatch = 500

// SetAnalyzer sets how messages are indexed from now on. Until it is called,
// messages are stored without being indexed.
func (s *Store) SetAnalyzer(a Analyzer) { s.analyzer.Store(&a) }

func (s *Store) currentAnalyzer() Analyzer {
	if p := s.analyzer.Load(); p != nil {
		return *p
	}
	return nil
}

// Reader returns the read-only connection pool, for packages that query the
// archive. Writes through it fail.
func (s *Store) Reader() *sql.DB { return s.r }

// IndexCurrent reports whether the whole index was built by the analyzer now set.
func (s *Store) IndexCurrent() (bool, error) {
	a := s.currentAnalyzer()
	if a == nil {
		return false, nil
	}
	built, _, err := s.Setting(indexSignatureKey)
	return built == a.Signature(), err
}

// indexMessage writes one message's index row from its current text and
// attachment file names, replacing any earlier row.
func indexMessage(tx *sql.Tx, a Analyzer, messageID int64) error {
	var doc strings.Builder
	var text string
	if err := tx.QueryRow(`SELECT text FROM messages WHERE id = ?`, messageID).Scan(&text); err != nil {
		return err
	}
	doc.WriteString(text)

	rows, err := tx.Query(`SELECT file_name FROM attachments WHERE message_id = ? AND file_name != '' ORDER BY position`, messageID)
	if err != nil {
		return err
	}
	for rows.Next() {
		var name string
		if err := rows.Scan(&name); err != nil {
			rows.Close()
			return err
		}
		doc.WriteByte('\n')
		doc.WriteString(name)
	}
	if err := rows.Close(); err != nil {
		return err
	}
	if err := rows.Err(); err != nil {
		return err
	}

	exact, stem := a.Index(doc.String())
	_, err = tx.Exec(`INSERT OR REPLACE INTO messages_fts (rowid, exact, stem) VALUES (?, ?, ?)`, messageID, exact, stem)
	return err
}

func (s *Store) inTx(ctx context.Context, fn func(tx *sql.Tx) error) error {
	tx, err := s.w.BeginTx(ctx, nil)
	if err != nil {
		return err
	}
	defer tx.Rollback()
	if err := fn(tx); err != nil {
		return err
	}
	return tx.Commit()
}

// Reindex rebuilds the search index from the archive with the analyzer now
// set. It works in small transactions, so ingestion continues meanwhile and
// messages that arrive during the rebuild are indexed as usual. The index is
// marked stale first and current only at the end, so an interrupted rebuild
// is detected by IndexCurrent and can simply be run again.
func (s *Store) Reindex(ctx context.Context, progress func(done, total int)) error {
	a := s.currentAnalyzer()
	if a == nil {
		return ErrNoAnalyzer
	}
	if progress == nil {
		progress = func(int, int) {}
	}

	err := s.inTx(ctx, func(tx *sql.Tx) error {
		if _, err := tx.Exec(`INSERT INTO settings (key, value) VALUES (?, '') ON CONFLICT (key) DO UPDATE SET value = ''`, indexSignatureKey); err != nil {
			return err
		}
		_, err := tx.Exec(`INSERT INTO messages_fts (messages_fts) VALUES ('delete-all')`)
		return err
	})
	if err != nil {
		return err
	}

	var total int
	if err := s.r.QueryRowContext(ctx, `SELECT COUNT(*) FROM messages`).Scan(&total); err != nil {
		return err
	}
	done, last := 0, int64(0)
	for {
		if err := ctx.Err(); err != nil {
			return err
		}
		var ids []int64
		err := s.inTx(ctx, func(tx *sql.Tx) error {
			rows, err := tx.Query(`SELECT id FROM messages WHERE id > ? ORDER BY id LIMIT ?`, last, reindexBatch)
			if err != nil {
				return err
			}
			for rows.Next() {
				var id int64
				if err := rows.Scan(&id); err != nil {
					rows.Close()
					return err
				}
				ids = append(ids, id)
			}
			if err := rows.Close(); err != nil {
				return err
			}
			if err := rows.Err(); err != nil {
				return err
			}
			for _, id := range ids {
				if err := indexMessage(tx, a, id); err != nil {
					return err
				}
			}
			return nil
		})
		if err != nil {
			if ctx.Err() != nil {
				return ctx.Err()
			}
			return err
		}
		if len(ids) == 0 {
			break
		}
		last = ids[len(ids)-1]
		done += len(ids)
		progress(done, total)
	}
	return s.SetSetting(indexSignatureKey, a.Signature())
}

package search

import (
	"strings"
	"unicode"
	"unicode/utf8"
)

// maxQueryTerms bounds a query, and a phrase, so that a pasted page of text
// cannot build an expression the index refuses.
const maxQueryTerms = 32

// parsed is a query in the two forms it is used: the expression the index is
// asked, and what a snippet should highlight.
type parsed struct {
	match    string          // FTS5 MATCH expression; empty when nothing is searchable
	exact    map[string]bool // exact forms of every query word
	stems    map[string]bool // stems of the unquoted words
	prefixes []string        // exact forms that match as a prefix
}

// Phones and word processors type these in place of a plain double quote.
var plainQuotes = strings.NewReplacer("“", `"`, "”", `"`, "„", `"`)

// parse turns what the owner typed into an FTS5 MATCH expression.
//
// Unquoted words are ANDed, each matching its exact form or any of its stems.
// Quoted text is a phrase on the exact column. Every term is emitted as a
// quoted string built from analyzer tokens, which contain only letters,
// numbers and marks, so nothing the owner types can act as FTS5 syntax.
func (a *Analyzer) parse(query string) parsed {
	p := parsed{exact: map[string]bool{}, stems: map[string]bool{}}
	query = plainQuotes.Replace(query)
	// A word still being typed matches as a prefix. Trailing space says it is finished.
	typing := strings.TrimRightFunc(query, unicode.IsSpace) == query

	var groups []string
	parts := strings.Split(query, `"`) // odd-numbered parts were inside quotes
	for i, part := range parts {
		tokens := a.Tokens(part)
		if len(tokens) == 0 {
			continue
		}
		if i%2 == 1 {
			groups = append(groups, p.phrase(tokens))
			continue
		}
		groups = append(groups, p.words(part, tokens, typing && i == len(parts)-1)...)
	}
	if len(groups) > maxQueryTerms {
		groups = groups[:maxQueryTerms]
	}
	p.match = strings.Join(groups, " AND ")
	return p
}

// phrase returns a phrase on the exact column.
func (p *parsed) phrase(tokens []Token) string {
	if len(tokens) > maxQueryTerms {
		tokens = tokens[:maxQueryTerms]
	}
	words := make([]string, len(tokens))
	for i, t := range tokens {
		words[i] = t.Exact
		p.exact[t.Exact] = true
	}
	return `exact:"` + strings.Join(words, " ") + `"`
}

// words returns one group per unquoted word of text.
func (p *parsed) words(text string, tokens []Token, lastIsPrefix bool) []string {
	var groups []string
	for i := 0; i < len(tokens); {
		t := tokens[i]
		if t.Gram {
			// The character pairs of one run overlap; together they are a phrase.
			j := i + 1
			for j < len(tokens) && tokens[j].Gram && tokens[j].Start < tokens[j-1].End {
				j++
			}
			if j == i+1 && utf8.RuneCountInString(text[t.Start:t.End]) == 1 {
				// One character is stored only as the start of a pair.
				p.exact[t.Exact] = true
				p.prefixes = append(p.prefixes, t.Exact)
				groups = append(groups, `exact:"`+t.Exact+`"*`)
			} else {
				groups = append(groups, p.phrase(tokens[i:j]))
			}
			i = j
			continue
		}

		p.exact[t.Exact] = true
		terms := make([]string, 0, 1+len(t.Stems))
		if lastIsPrefix && i == len(tokens)-1 {
			p.prefixes = append(p.prefixes, t.Exact)
			terms = append(terms, `exact:"`+t.Exact+`"*`)
		} else {
			terms = append(terms, `exact:"`+t.Exact+`"`)
		}
		for _, s := range t.Stems {
			p.stems[s] = true
			terms = append(terms, `stem:"`+s+`"`)
		}
		if len(terms) == 1 {
			groups = append(groups, terms[0])
		} else {
			groups = append(groups, "("+strings.Join(terms, " OR ")+")")
		}
		i++
	}
	return groups
}

package search

import (
	"strings"
	"unicode/utf8"
)

// Fragment is a piece of a snippet. Match fragments are the words the query found.
type Fragment struct {
	Text  string
	Match bool
}

const (
	// snippetRunes is the most text a snippet shows, in characters.
	snippetRunes = 160
	// snippetLead is how much text is shown before the first match.
	snippetLead = 40
)

var flatten = strings.NewReplacer("\n", " ", "\r", " ", "\t", " ")

// matches reports whether a token of the text is one the query was looking for.
func (p parsed) matches(t Token) bool {
	if p.exact[t.Exact] {
		return true
	}
	for _, s := range t.Stems {
		if p.stems[s] {
			return true
		}
	}
	for _, prefix := range p.prefixes {
		if strings.HasPrefix(t.Exact, prefix) {
			return true
		}
	}
	return false
}

// matchSpans returns the byte ranges of text the query matched, in order,
// with touching and overlapping ranges merged.
func (a *Analyzer) matchSpans(text string, p parsed) [][2]int {
	var spans [][2]int
	for _, t := range a.Tokens(text) {
		if !p.matches(t) {
			continue
		}
		if n := len(spans); n > 0 && t.Start <= spans[n-1][1] {
			spans[n-1][1] = max(spans[n-1][1], t.End)
			continue
		}
		spans = append(spans, [2]int{t.Start, t.End})
	}
	return spans
}

// back and forward move a byte offset by up to n characters, staying on character boundaries.
func back(text string, pos, n int) int {
	for ; n > 0 && pos > 0; n-- {
		_, size := utf8.DecodeLastRuneInString(text[:pos])
		pos -= size
	}
	return pos
}

func forward(text string, pos, n int) int {
	for ; n > 0 && pos < len(text); n-- {
		_, size := utf8.DecodeRuneInString(text[pos:])
		pos += size
	}
	return pos
}

// snippet returns up to snippetRunes characters of text around the first
// match, or the start of the text if nothing matches, with "…" fragments
// where text was cut.
func (a *Analyzer) snippet(text string, p parsed) []Fragment {
	if text == "" {
		return nil
	}
	spans := a.matchSpans(text, p)
	start := 0
	if len(spans) > 0 {
		start = back(text, spans[0][0], snippetLead)
	}
	end := forward(text, start, snippetRunes)

	var out []Fragment
	add := func(from, to int, match bool) {
		if from < to {
			out = append(out, Fragment{Text: flatten.Replace(text[from:to]), Match: match})
		}
	}
	if start > 0 {
		out = append(out, Fragment{Text: "…"})
	}
	pos := start
	for _, span := range spans {
		if span[0] >= end {
			break
		}
		add(pos, span[0], false)
		add(span[0], min(span[1], end), true)
		pos = min(span[1], end)
	}
	add(pos, end, false)
	if end < len(text) {
		out = append(out, Fragment{Text: "…"})
	}
	return out
}

package search

import (
	"context"
	"database/sql"
	"strings"
	"time"

	"github.com/fenelon/arc5/internal/model"
)

type Sort int

const (
	ByRelevance Sort = iota // best match first; exact words above word forms
	ByNewest
)

const (
	DefaultLimit = 50
	MaxLimit     = 200
)

// Query is a search request. IDs are database IDs; zero means any.
type Query struct {
	Text           string
	AccountID      int64
	ChatID         int64
	SenderID       int64
	From           time.Time // inclusive; zero means unbounded
	To             time.Time // exclusive; zero means unbounded
	HasAttachment  bool
	DeletedOnly    bool // only messages deleted at the source
	IncludeService bool // also joins, calls and other service messages
	Sort           Sort
	Limit          int // zero means DefaultLimit; capped at MaxLimit
	Offset         int
}

// Hit is one found message, with what a result row shows.
type Hit struct {
	MessageID  int64
	AccountID  int64
	ChatID     int64
	ChatTitle  string
	SenderName string
	Kind       model.MessageKind
	SentAt     time.Time
	Edited     bool
	Deleted    bool
	Snippet    []Fragment
}

type Page struct {
	Hits []Hit
	More bool // further hits exist past this page
}

// Searcher runs queries against the archive's index.
type Searcher struct {
	db       *sql.DB
	analyzer *Analyzer
}

// New returns a Searcher that reads through db, normally archive.Store.Reader.
// The analyzer must be the one the index was built with.
func New(db *sql.DB, a *Analyzer) *Searcher {
	return &Searcher{db: db, analyzer: a}
}

// Search finds messages. With empty Text it lists messages by the filters
// alone, newest first. Text that holds nothing searchable finds nothing.
func (s *Searcher) Search(ctx context.Context, q Query) (Page, error) {
	p := s.analyzer.parse(q.Text)
	if p.match == "" && strings.TrimSpace(q.Text) != "" {
		return Page{}, nil
	}
	limit := q.Limit
	if limit <= 0 {
		limit = DefaultLimit
	}
	limit = min(limit, MaxLimit)
	offset := max(q.Offset, 0)

	from := `messages m`
	order := `m.sent_at DESC, m.id DESC`
	var (
		where []string
		args  []any
	)
	add := func(condition string, values ...any) {
		where = append(where, condition)
		args = append(args, values...)
	}
	if p.match != "" {
		from = `messages_fts JOIN messages m ON m.id = messages_fts.rowid`
		add(`messages_fts MATCH ?`, p.match)
		if q.Sort == ByRelevance {
			order = `bm25(messages_fts, 2.0, 1.0), m.sent_at DESC, m.id DESC`
		}
	}
	if q.AccountID != 0 {
		add(`c.account_id = ?`, q.AccountID)
	}
	if q.ChatID != 0 {
		add(`m.chat_id = ?`, q.ChatID)
	}
	if q.SenderID != 0 {
		add(`m.sender_id = ?`, q.SenderID)
	}
	if !q.From.IsZero() {
		add(`m.sent_at >= ?`, q.From.Unix())
	}
	if !q.To.IsZero() {
		add(`m.sent_at < ?`, q.To.Unix())
	}
	if q.HasAttachment {
		add(`EXISTS (SELECT 1 FROM attachments a WHERE a.message_id = m.id)`)
	}
	if q.DeletedOnly {
		add(`m.deleted_at IS NOT NULL`)
	}
	if !q.IncludeService {
		add(`m.kind = 'message'`)
	}

	query := `
		SELECT m.id, c.account_id, c.id, c.title, COALESCE(sn.display_name, ''), m.kind, m.sent_at,
		       m.edited_at IS NOT NULL, m.deleted_at IS NOT NULL, m.text
		FROM ` + from + `
		JOIN chats c ON c.id = m.chat_id
		LEFT JOIN senders sn ON sn.id = m.sender_id`
	if len(where) > 0 {
		query += ` WHERE ` + strings.Join(where, ` AND `)
	}
	query += ` ORDER BY ` + order + ` LIMIT ? OFFSET ?`
	args = append(args, limit+1, offset) // one extra row tells us whether more exist

	rows, err := s.db.QueryContext(ctx, query, args...)
	if err != nil {
		return Page{}, err
	}
	defer rows.Close()
	var page Page
	for rows.Next() {
		var (
			h    Hit
			kind string
			sent int64
			text string
		)
		if err := rows.Scan(&h.MessageID, &h.AccountID, &h.ChatID, &h.ChatTitle, &h.SenderName, &kind, &sent, &h.Edited, &h.Deleted, &text); err != nil {
			return Page{}, err
		}
		if len(page.Hits) == limit {
			page.More = true
			break
		}
		h.Kind = model.MessageKind(kind)
		h.SentAt = time.Unix(sent, 0).UTC()
		h.Snippet = s.analyzer.snippet(text, p)
		page.Hits = append(page.Hits, h)
	}
	return page, rows.Err()
}

// Reindex holds the arguments of `arc5 reindex`.
type Reindex struct {
	DataDir   string
	Languages string // comma-separated codes; empty keeps the current list
}

// ParseReindex reads `reindex` arguments.
func ParseReindex(args []string, getenv func(string) string) (Reindex, error) {
	cfg := Reindex{DataDir: "data"}
	if v := getenv("ARC5_DATA"); v != "" {
		cfg.DataDir = v
	}

	fs := flag.NewFlagSet("reindex", flag.ContinueOnError)
	fs.SetOutput(io.Discard)
	fs.StringVar(&cfg.DataDir, "data", cfg.DataDir, "data folder (ARC5_DATA)")
	fs.StringVar(&cfg.Languages, "languages", "", "languages to stem, comma-separated, for example en,ru,es")
	if err := fs.Parse(args); err != nil {
		return Reindex{}, err
	}
	if fs.NArg() > 0 {
		return Reindex{}, fmt.Errorf("unexpected argument %q", fs.Arg(0))
	}
	return cfg, nil
}

// Command arc5 is a self-hosted message archive.
package main

import (

const usage = `usage:
  arc5 serve   [--listen address] [--data folder]
  arc5 reindex [--data folder] [--languages en,ru,es]`

// languagesKey is the setting that holds the languages search stems, as
// comma-separated codes.
const languagesKey = "search_languages"

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()
	if err := run(ctx, os.Args[1:], os.Getenv, nil); err != nil {
		fmt.Fprintln(os.Stderr, "arc5:", err)
		os.Exit(1)
	}
}

// run executes one command. ready, if set, is called with the listening
// address once the server accepts connections.
func run(ctx context.Context, args []string, getenv func(string) string, ready func(addr string)) error {
	if len(args) == 0 {
		return errors.New(usage)
	}
	switch args[0] {
	case "serve":
		cfg, err := config.Parse(args[1:], getenv)
		if err != nil {
			return fmt.Errorf("%w\n%s", err, usage)
		}
		return serve(ctx, cfg, ready)
	case "reindex":
		cfg, err := config.ParseReindex(args[1:], getenv)
		if err != nil {
			return fmt.Errorf("%w\n%s", err, usage)
		}
		return reindex(ctx, cfg)
	default:
		return fmt.Errorf("unknown command %q\n%s", args[0], usage)
	}
}

// loadAnalyzer builds the search analyzer for the languages in settings.
func loadAnalyzer(store *archive.Store) (*search.Analyzer, error) {
	setting, ok, err := store.Setting(languagesKey)
	if err != nil {
		return nil, err
	}
	if !ok {
		setting = search.DefaultLanguages
	}
	analyzer, err := search.NewAnalyzer(search.ParseLanguages(setting))
	if err != nil {
		return nil, fmt.Errorf("%s setting: %w", languagesKey, err)
	}
	return analyzer, nil
}

func serve(ctx context.Context, cfg config.Config, ready func(addr string)) error {
	store, err := archive.Open(cfg.DataDir)
	if err != nil {
		return err
	}
	defer store.Close()

	analyzer, err := loadAnalyzer(store)
	if err != nil {
		return err
	}
	store.SetAnalyzer(analyzer)
	current, err := store.IndexCurrent()
	if err != nil {
		return err
	}

	ln, err := net.Listen("tcp", cfg.Listen)
	if err != nil {
		return fmt.Errorf("listen on %s: %w", cfg.Listen, err)
	}

	// Connectors and the index rebuild stop before the store closes,
	// whichever way serve returns.
	ctx, cancel := context.WithCancel(ctx)
	runner := connector.NewRunner(store, connector.Default)
	var background sync.WaitGroup
	defer func() {
		cancel()
		runner.Wait()
		background.Wait()
	}()

	if !current {
		background.Add(1)
		go func() {
			defer background.Done()
			log.Printf("rebuilding the search index for %s", analyzer.Signature())
			if err := store.Reindex(ctx, nil); err != nil {
				if ctx.Err() == nil {
					log.Printf("search index rebuild failed: %v", err)
				}
				return
			}
			log.Printf("search index rebuilt")
		}()
	}
	if err := runner.Start(ctx); err != nil {
		ln.Close()
		return err
	}

	srv := &http.Server{Handler: web.NewHandler(), ReadHeaderTimeout: 10 * time.Second}
	served := make(chan error, 1)
	go func() { served <- srv.Serve(ln) }()
	log.Printf("arc5 listening on http://%s, data in %s", ln.Addr(), cfg.DataDir)
	if ready != nil {
		ready(ln.Addr().String())
	}

	select {
	case err := <-served:
		return err
	case <-ctx.Done():
	}
	shutdownCtx, cancelShutdown := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancelShutdown()
	return srv.Shutdown(shutdownCtx)
}

// reindex rebuilds the search index, changing the language list first if one
// was given. It may run while a server has the same data folder open, but a
// running server keeps its old language list until it is restarted.
func reindex(ctx context.Context, cfg config.Reindex) error {
	store, err := archive.Open(cfg.DataDir)
	if err != nil {
		return err
	}
	defer store.Close()

	if cfg.Languages != "" {
		chosen, err := search.NewAnalyzer(search.ParseLanguages(cfg.Languages))
		if err != nil {
			return err
		}
		if err := store.SetSetting(languagesKey, strings.Join(chosen.Languages(), ",")); err != nil {
			return err
		}
	}
	analyzer, err := loadAnalyzer(store)
	if err != nil {
		return err
	}
	store.SetAnalyzer(analyzer)

	indexed := 0
	if err := store.Reindex(ctx, func(done, total int) { indexed = done }); err != nil {
		return err
	}
	languages := strings.Join(analyzer.Languages(), ", ")
	if languages == "" {
		languages = "none"
	}
	fmt.Printf("indexed %d messages; word forms for: %s\n", indexed, languages)
	return nil
}

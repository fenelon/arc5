# arc5 Core (Milestone 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running `arc5 serve` process with a durable archive store, the connector interface, a supervising runner, and a scripted fake connector that proves the ingest contract.

**Architecture:** One Go binary. `internal/model` holds the event types. `internal/archive` is the only database writer (SQLite in WAL mode, one write connection, a read-only pool) and owns media files. `internal/connector` defines the connector interface, the per-account sink and state, and a runner that supervises connectors with backoff. `cmd/arc5` wires them behind an HTTP server that so far only answers `/healthz`.

**Tech Stack:** Go 1.26, `modernc.org/sqlite` (pure Go), standard library only otherwise.

**Spec:** `docs/superpowers/specs/2026-10-12-message-archive-design.md` (sections 2, 3, 4, 9, 10, 12). This plan is milestone 1 of the five in section 12. Search, the web interface, the Telegram connector, and alerts/backup/Docker each get their own plan.

## Global Constraints

- Module path is `github.com/fenelon/arc5`; binary name `arc5`; environment prefix `ARC5_`.
- No cgo. The SQLite driver is `modernc.org/sqlite`, driver name `sqlite`.
- Data folder mode `0700`; `arc5.db` mode `0600`; media files mode `0600`.
- SQLite runs in WAL mode.
- `internal/archive` is the only package that writes to the database or the media folder.
- Nothing is removed from the archive because the source removed it: deletions set `deleted_at`, edits add a `message_versions` row.
- Ingest is idempotent on `(chat, source_id)`.
- Media size cap defaults to 50 MB (`50 << 20` bytes).
- Runner restart backoff is exponential and capped at five minutes.
- Default listen address is `127.0.0.1:8080`.
- Times are stored as Unix seconds (UTC) in `INTEGER` columns.
- Every task ends with `go vet ./... && go test -race ./...` passing.

## Where this plan refines the spec

- **Storage failures pause per account.** The spec says ingestion pauses "for all accounts" when writes fail. Here each connector pauses when its own write fails (`ErrStorage` puts it in the `paused` state and it retries with backoff). A full disk fails every account's next write, so the effect is the same without a global switch.
- **Raw payloads are gzip-compressed**, using the standard library, to avoid a dependency.

## Review Focus

1. **Crash replay after an edit.** A connector that replays the original copy of a message after its edit was stored must not revert the text or add a bogus version. Pinned in Task 3.
2. **Deletion of something never captured, and re-ingest of something deleted.** `MarkDeleted` on unknown IDs is a no-op, and a later upsert never clears `deleted_at`. Pinned in Task 3.
3. **Backfill and live capture writing at once.** Concurrent upserts must not fail with "database is locked". Pinned in Task 3.
4. **A media download dying mid-stream.** No partial file is kept, no temp file is left, and the attachment stays `pending`. Pinned in Task 4.
5. **A connector that panics.** The process survives and the runner restarts the connector. Pinned in Task 6.

// Package archive is the only writer to the arc5 database and media folder.
package archive

import (
	"database/sql"
	"embed"
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"sort"
	"strconv"
	"strings"
	"time"

	_ "modernc.org/sqlite"
)

//go:embed migrations/*.sql
var migrationFiles embed.FS

const dbFile = "arc5.db"

// Store owns the database and the media folder under one data directory.
type Store struct {
	w       *sql.DB // single connection; every write goes through it
	r       *sql.DB // read-only pool
	dataDir string
	now     func() time.Time
}

// Open creates the data folder and database if needed and applies migrations.
func Open(dataDir string) (*Store, error) {
	if err := os.MkdirAll(dataDir, 0o700); err != nil {
		return nil, fmt.Errorf("create data folder: %w", err)
	}
	if err := os.Chmod(dataDir, 0o700); err != nil {
		return nil, fmt.Errorf("restrict data folder: %w", err)
	}
	path := filepath.Join(dataDir, dbFile)
	f, err := os.OpenFile(path, os.O_RDWR|os.O_CREATE, 0o600)
	if err != nil {
		return nil, fmt.Errorf("create database: %w", err)
	}
	f.Close()
	if err := os.Chmod(path, 0o600); err != nil {
		return nil, fmt.Errorf("restrict database: %w", err)
	}

	const common = "?_pragma=busy_timeout(5000)&_pragma=foreign_keys(1)"
	w, err := sql.Open("sqlite", path+common+"&_pragma=journal_mode(WAL)&_pragma=synchronous(NORMAL)")
	if err != nil {
		return nil, fmt.Errorf("open database: %w", err)
	}
	// One writer avoids SQLITE_BUSY between connectors; database/sql queues callers.
	w.SetMaxOpenConns(1)
	r, err := sql.Open("sqlite", path+common+"&_pragma=query_only(1)")
	if err != nil {
		w.Close()
		return nil, fmt.Errorf("open database for reading: %w", err)
	}

	s := &Store{w: w, r: r, dataDir: dataDir, now: time.Now}
	if err := s.migrate(); err != nil {
		s.Close()
		return nil, err
	}
	return s, nil
}

func (s *Store) Close() error {
	return errors.Join(s.r.Close(), s.w.Close())
}

func (s *Store) migrate() error {
	if _, err := s.w.Exec(`CREATE TABLE IF NOT EXISTS schema_migrations (version INTEGER PRIMARY KEY, applied_at INTEGER NOT NULL)`); err != nil {
		return fmt.Errorf("prepare migrations: %w", err)
	}
	entries, err := migrationFiles.ReadDir("migrations")
	if err != nil {
		return err
	}
	names := make([]string, 0, len(entries))
	for _, e := range entries {
		names = append(names, e.Name())
	}
	sort.Strings(names)

	for _, name := range names {
		version, err := strconv.Atoi(strings.SplitN(name, "_", 2)[0])
		if err != nil {
			return fmt.Errorf("migration %s: name must start with a number", name)
		}
		var applied int
		if err := s.w.QueryRow(`SELECT COUNT(*) FROM schema_migrations WHERE version = ?`, version).Scan(&applied); err != nil {
			return err
		}
		if applied > 0 {
			continue
		}
		body, err := migrationFiles.ReadFile("migrations/" + name)
		if err != nil {
			return err
		}
		tx, err := s.w.Begin()
		if err != nil {
			return err
		}
		if _, err := tx.Exec(string(body)); err != nil {
			tx.Rollback()
			return fmt.Errorf("migration %s: %w", name, err)
		}
		if _, err := tx.Exec(`INSERT INTO schema_migrations (version, applied_at) VALUES (?, ?)`, version, s.now().Unix()); err != nil {
			tx.Rollback()
			return fmt.Errorf("migration %s: %w", name, err)
		}
		if err := tx.Commit(); err != nil {
			return fmt.Errorf("migration %s: %w", name, err)
		}
	}
	return nil
}
```

	if b {
		return 1
	}
	return 0

	if t.IsZero() {
		return 0
	}
	return t.Unix()
}

func nullUnix(v int64) any {
	if v == 0 {
		return nil
	}
	return v
}

	if !v.Valid {

	}
	return time.Unix(v.Int64, 0).UTC()

package archive

import (
	"database/sql"
	"encoding/json"
	"errors"
	"fmt"
	"time"
)

// Account is one configured instance of a connector.
type Account struct {
	ID        int64
	Connector string
	Label     string
	Settings  map[string]string
	Enabled   bool
	CreatedAt time.Time
}

const accountColumns = `id, connector, label, settings, enabled, created_at`

func encodeSettings(settings map[string]string) (string, error) {
	if settings == nil {
		settings = map[string]string{}
	}
	body, err := json.Marshal(settings)
	return string(body), err
}

func scanAccount(row interface{ Scan(dest ...any) error }) (Account, error) {
	var (
		a        Account
		settings string
		enabled  int
		created  int64
	)
	if err := row.Scan(&a.ID, &a.Connector, &a.Label, &settings, &enabled, &created); err != nil {
		return Account{}, err
	}
	a.Settings = map[string]string{}
	if err := json.Unmarshal([]byte(settings), &a.Settings); err != nil {
		return Account{}, fmt.Errorf("account %d settings: %w", a.ID, err)
	}
	a.Enabled = enabled != 0
	a.CreatedAt = time.Unix(created, 0).UTC()
	return a, nil
}

func (s *Store) CreateAccount(connector, label string, settings map[string]string) (int64, error) {
	if connector == "" {
		return 0, fmt.Errorf("%w: account needs a connector name", ErrInvalid)
	}
	body, err := encodeSettings(settings)
	if err != nil {
		return 0, err
	}
	res, err := s.w.Exec(`INSERT INTO accounts (connector, label, settings, enabled, created_at) VALUES (?, ?, ?, 1, ?)`,
		connector, clean(label), body, s.now().Unix())
	if err != nil {
		return 0, err
	}
	return res.LastInsertId()
}

func (s *Store) Account(id int64) (Account, error) {
	a, err := scanAccount(s.r.QueryRow(`SELECT `+accountColumns+` FROM accounts WHERE id = ?`, id))
	if errors.Is(err, sql.ErrNoRows) {
		return Account{}, fmt.Errorf("account %d: %w", id, ErrNotFound)
	}
	return a, err
}

func (s *Store) Accounts() ([]Account, error) {
	rows, err := s.r.Query(`SELECT ` + accountColumns + ` FROM accounts ORDER BY id`)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	var out []Account
	for rows.Next() {
		a, err := scanAccount(rows)
		if err != nil {
			return nil, err
		}
		out = append(out, a)
	}
	return out, rows.Err()
}

func (s *Store) UpdateAccountSettings(id int64, settings map[string]string) error {
	body, err := encodeSettings(settings)
	if err != nil {
		return err
	}
	return s.updateAccount(id, `UPDATE accounts SET settings = ? WHERE id = ?`, body, id)
}

func (s *Store) SetAccountEnabled(id int64, enabled bool) error {
	return s.updateAccount(id, `UPDATE accounts SET enabled = ? WHERE id = ?`, b2i(enabled), id)
}

func (s *Store) updateAccount(id int64, query string, args ...any) error {
	res, err := s.w.Exec(query, args...)
	if err != nil {
		return err
	}
	n, err := res.RowsAffected()
	if err != nil {
		return err
	}
	if n == 0 {
		return fmt.Errorf("account %d: %w", id, ErrNotFound)
	}
	return nil
}

// UpsertChat records a chat. A chat seen for the first time is archived or not
// according to its kind; later upserts refresh the title and never change that choice.
func (s *Store) UpsertChat(accountID int64, c model.Chat) error {
	if c.SourceID == "" {
		return fmt.Errorf("%w: chat needs a source ID", ErrInvalid)
	}
	if !c.Kind.Valid() {
		return fmt.Errorf("%w: chat kind %q", ErrInvalid, c.Kind)
	}
	_, err := s.w.Exec(`
		INSERT INTO chats (account_id, source_id, kind, title, archived, created_at)
		VALUES (?, ?, ?, ?, ?, ?)
		ON CONFLICT (account_id, source_id) DO UPDATE SET title = excluded.title, kind = excluded.kind`,
		accountID, c.SourceID, string(c.Kind), clean(c.Title), b2i(c.Kind.ArchivedByDefault()), s.now().Unix())
	return err
}

func (s *Store) UpsertSender(accountID int64, sn model.Sender) error {
	if sn.SourceID == "" {
		return fmt.Errorf("%w: sender needs a source ID", ErrInvalid)
	}
	_, err := s.w.Exec(`
		INSERT INTO senders (account_id, source_id, display_name, username)
		VALUES (?, ?, ?, ?)
		ON CONFLICT (account_id, source_id) DO UPDATE SET display_name = excluded.display_name, username = excluded.username`,
		accountID, sn.SourceID, clean(sn.DisplayName), clean(sn.Username))
	return err
}

const mediaCapKey = "media_cap_bytes"

func (s *Store) Setting(key string) (string, bool, error) {

	err := s.r.QueryRow(`SELECT value FROM settings WHERE key = ?`, key).Scan(&v)

		return "", false, nil
	}
	return v, err == nil, err
}

func (s *Store) SetSetting(key, value string) error {
	_, err := s.w.Exec(`INSERT INTO settings (key, value) VALUES (?, ?) ON CONFLICT (key) DO UPDATE SET value = excluded.value`, key, value)
	return err
}

func mediaCap(q queryer) (int64, error) {
	var v string
	err := q.QueryRow(`SELECT value FROM settings WHERE key = ?`, mediaCapKey).Scan(&v)
	if errors.Is(err, sql.ErrNoRows) {
		return DefaultMediaCap, nil
	}
	if err != nil {
		return 0, err
	}
	n, err := strconv.ParseInt(v, 10, 64)
	if err != nil {
		return 0, fmt.Errorf("%s setting: %w", mediaCapKey, err)
	}
	return n, nil
}

func (s *Store) MediaCap() (int64, error) { return mediaCap(s.r) }

func (s *Store) SetMediaCap(n int64) error {
	if n < 0 {
		return fmt.Errorf("%w: media cap cannot be negative", ErrInvalid)
	}
	return s.SetSetting(mediaCapKey, strconv.FormatInt(n, 10))
}

	err := s.r.QueryRow(`SELECT value FROM connector_state WHERE account_id = ? AND key = ?`, accountID, key).Scan(&v)

		ON CONFLICT (account_id, key) DO UPDATE SET value = excluded.value`, accountID, key, value)

package archive

const reasonOverCap = "over size cap"

// UpsertMessage stores a new message or applies an edit, and returns the
// attachments of that message still waiting to be downloaded.
//
// It is idempotent. An upsert whose edit time is older than the stored one is
// ignored, so replaying an original never reverts a later edit. Attachments
// are recorded when their position is first seen and are not changed by edits.
func (s *Store) UpsertMessage(accountID int64, m model.Message) ([]model.AttachmentRef, error) {
	if m.SourceID == "" {
		return nil, fmt.Errorf("%w: message needs a source ID", ErrInvalid)
	}
	if m.SentAt.IsZero() {
		return nil, fmt.Errorf("%w: message %q needs a sent time", ErrInvalid, m.SourceID)
	}
	if m.Kind == "" {
		m.Kind = model.KindMessage
	}
	if !m.Kind.Valid() {
		return nil, fmt.Errorf("%w: message kind %q", ErrInvalid, m.Kind)
	}
	for _, a := range m.Attachments {
		if !a.Kind.Valid() {
			return nil, fmt.Errorf("%w: attachment kind %q", ErrInvalid, a.Kind)
		}
	}
	raw, err := compress(m.Raw)
	if err != nil {
		return nil, err
	}
	text := clean(m.Text)
	now := s.now().Unix()
	incomingEdit := unixOrZero(m.EditedAt)

	tx, err := s.w.Begin()
	if err != nil {
		return nil, err
	}
	defer tx.Rollback()

	chat, err := chatID(tx, accountID, m.ChatSourceID)
	if err != nil {
		return nil, err
	}
	sender, err := senderID(tx, accountID, m.SenderSourceID)
	if err != nil {
		return nil, err
	}

	var (
		id         int64
		storedText string
		storedEdit sql.NullInt64
	)
	err = tx.QueryRow(`SELECT id, text, edited_at FROM messages WHERE chat_id = ? AND source_id = ?`, chat, m.SourceID).
		Scan(&id, &storedText, &storedEdit)
	switch {
	case errors.Is(err, sql.ErrNoRows):
		res, err := tx.Exec(`
			INSERT INTO messages (chat_id, source_id, sender_id, kind, sent_at, text,
			                      reply_to_source_id, forwarded_from, edited_at, captured_at, raw)
			VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
			chat, m.SourceID, sender, string(m.Kind), m.SentAt.Unix(), text,
			m.ReplyToSourceID, clean(m.ForwardedFrom), nullUnix(incomingEdit), now, raw)
		if err != nil {
			return nil, err
		}
		if id, err = res.LastInsertId(); err != nil {
			return nil, err
		}
	case err != nil:
		return nil, err
	case incomingEdit >= storedEdit.Int64 && text != storedText:
		if _, err := tx.Exec(`INSERT INTO message_versions (message_id, text, replaced_at) VALUES (?, ?, ?)`, id, storedText, now); err != nil {
			return nil, err
		}
		editedAt := incomingEdit
		if editedAt == 0 {
			editedAt = now
		}
		if _, err := tx.Exec(`UPDATE messages SET text = ?, edited_at = ?, raw = COALESCE(?, raw) WHERE id = ?`, text, editedAt, raw, id); err != nil {
			return nil, err
		}
	case incomingEdit > storedEdit.Int64:
		if _, err := tx.Exec(`UPDATE messages SET edited_at = ? WHERE id = ?`, incomingEdit, id); err != nil {
			return nil, err
		}
	}

	limit, err := mediaCap(tx)
	if err != nil {
		return nil, err
	}
	for position, a := range m.Attachments {
		status, reason := model.StatusPending, ""
		switch {
		case a.NoFetch:
			status, reason = model.StatusSkipped, a.NoFetchReason
		case a.Size > limit:
			status, reason = model.StatusSkipped, reasonOverCap
		}
		if _, err := tx.Exec(`
			INSERT INTO attachments (message_id, position, kind, file_name, mime_type, size, status, reason, ephemeral)
			VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
			ON CONFLICT (message_id, position) DO NOTHING`,
			id, position, string(a.Kind), clean(a.FileName), clean(a.MimeType), a.Size, string(status), clean(reason), b2i(a.Ephemeral)); err != nil {
			return nil, err
		}
	}

	rows, err := tx.Query(`SELECT position FROM attachments WHERE message_id = ? AND status = 'pending' ORDER BY position`, id)
	if err != nil {
		return nil, err
	}
	var pending []model.AttachmentRef
	for rows.Next() {
		ref := model.AttachmentRef{ChatSourceID: m.ChatSourceID, MessageSourceID: m.SourceID}
		if err := rows.Scan(&ref.Position); err != nil {
			rows.Close()
			return nil, err
		}
		pending = append(pending, ref)
	}
	if err := rows.Close(); err != nil {
		return nil, err
	}
	if err := rows.Err(); err != nil {
		return nil, err
	}
	return pending, tx.Commit()
}

// senderID returns the sender's row ID, creating a nameless sender if the
// connector has not described it yet, so a message is never lost over ordering.
func senderID(tx *sql.Tx, accountID int64, sourceID string) (sql.NullInt64, error) {
	if sourceID == "" {
		return sql.NullInt64{}, nil
	}
	if _, err := tx.Exec(`INSERT INTO senders (account_id, source_id) VALUES (?, ?) ON CONFLICT (account_id, source_id) DO NOTHING`, accountID, sourceID); err != nil {
		return sql.NullInt64{}, err
	}
	var id int64
	err := tx.QueryRow(`SELECT id FROM senders WHERE account_id = ? AND source_id = ?`, accountID, sourceID).Scan(&id)
	return sql.NullInt64{Int64: id, Valid: err == nil}, err
}

// MarkDeleted records that the source deleted these messages. Nothing is
// removed. Unknown chats and messages are ignored, and a message already
// marked keeps its first deletion time.
func (s *Store) MarkDeleted(accountID int64, chatSourceID string, messageSourceIDs []string) error {
	tx, err := s.w.Begin()
	if err != nil {
		return err
	}
	defer tx.Rollback()
	now := s.now().Unix()
	for _, id := range messageSourceIDs {
		if _, err := tx.Exec(`
			UPDATE messages SET deleted_at = ?
			WHERE deleted_at IS NULL AND source_id = ?
			  AND chat_id = (SELECT id FROM chats WHERE account_id = ? AND source_id = ?)`,
			now, id, accountID, chatSourceID); err != nil {
			return err
		}
	}
	return tx.Commit()
}

// LookupChats returns the source IDs of this account's chats of the given
// kinds that hold a message with this source ID. Connectors use it when the
// source reports a deletion without naming the chat.
func (s *Store) LookupChats(accountID int64, messageSourceID string, kinds []model.ChatKind) ([]string, error) {
	if len(kinds) == 0 {
		return nil, nil
	}
	args := []any{accountID, messageSourceID}
	for _, k := range kinds {
		args = append(args, string(k))
	}
	placeholders := strings.TrimSuffix(strings.Repeat("?,", len(kinds)), ",")
	rows, err := s.r.Query(`
		SELECT c.source_id FROM messages m JOIN chats c ON c.id = m.chat_id
		WHERE c.account_id = ? AND m.source_id = ? AND c.kind IN (`+placeholders+`)
		ORDER BY c.source_id`, args...)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	var out []string
	for rows.Next() {
		var id string
		if err := rows.Scan(&id); err != nil {
			return nil, err
		}
		out = append(out, id)
	}
	return out, rows.Err()
}

type StoredMessage struct {
	ID              int64
	SourceID        string
	SenderSourceID  string
	Kind            model.MessageKind
	SentAt          time.Time
	Text            string
	ReplyToSourceID string
	ForwardedFrom   string
	EditedAt        time.Time
	DeletedAt       time.Time

func (s *Store) Message(accountID int64, chatSourceID, sourceID string) (StoredMessage, error) {
	var (
		m               StoredMessage
		kind            string
		sent            int64
		edited, deleted sql.NullInt64
	)
	err := s.r.QueryRow(`
		SELECT m.id, m.source_id, COALESCE(sn.source_id, ''), m.kind, m.sent_at, m.text,
		       m.reply_to_source_id, m.forwarded_from, m.edited_at, m.deleted_at
		FROM messages m
		JOIN chats c ON c.id = m.chat_id
		LEFT JOIN senders sn ON sn.id = m.sender_id
		WHERE c.account_id = ? AND c.source_id = ? AND m.source_id = ?`,
		accountID, chatSourceID, sourceID).
		Scan(&m.ID, &m.SourceID, &m.SenderSourceID, &kind, &sent, &m.Text, &m.ReplyToSourceID, &m.ForwardedFrom, &edited, &deleted)
	if errors.Is(err, sql.ErrNoRows) {
		return StoredMessage{}, fmt.Errorf("message %q in chat %q: %w", sourceID, chatSourceID, ErrNotFound)
	}
	if err != nil {
		return StoredMessage{}, err
	}
	m.Kind = model.MessageKind(kind)
	m.SentAt = time.Unix(sent, 0).UTC()
	m.EditedAt, m.DeletedAt = fromUnix(edited), fromUnix(deleted)
	return m, nil
}

}

type StoredAttachment struct {

	Position  int

	MimeType  string

	Status    model.AttachmentStatus

func (s *Store) Attachments(messageID int64) ([]StoredAttachment, error) {
	rows, err := s.r.Query(`
		SELECT id, position, kind, file_name, mime_type, size, sha256, status, reason, ephemeral, requested
		FROM attachments WHERE message_id = ? ORDER BY position`, messageID)

	defer rows.Close()
	var out []StoredAttachment
	for rows.Next() {

			return nil, err

	}

// Raw returns the source's original payload for a message, or nil if none was stored.
func (s *Store) Raw(messageID int64) ([]byte, error) {
	var packed []byte
	err := s.r.QueryRow(`SELECT raw FROM messages WHERE id = ?`, messageID).Scan(&packed)
	if errors.Is(err, sql.ErrNoRows) {
		return nil, fmt.Errorf("message %d: %w", messageID, ErrNotFound)
	}
	if err != nil || packed == nil {
		return nil, err
	}
	zr, err := gzip.NewReader(bytes.NewReader(packed))
	if err != nil {
		return nil, err
	}
	defer zr.Close()
	return io.ReadAll(zr)
}

func (s *Store) MessageCount(accountID int64, chatSourceID string) (int, error) {
	var n int
	err := s.r.QueryRow(`
		SELECT COUNT(*) FROM messages m JOIN chats c ON c.id = m.chat_id
		WHERE c.account_id = ? AND c.source_id = ?`, accountID, chatSourceID).Scan(&n)
	return n, err
}

// compress gzips a payload. An empty payload yields an untyped nil, which the
// driver stores as NULL (a nil []byte is not guaranteed to be).
func compress(raw []byte) (any, error) {
	if len(raw) == 0 {
		return nil, nil
	}
	var buf bytes.Buffer
	zw := gzip.NewWriter(&buf)
	if _, err := zw.Write(raw); err != nil {
		return nil, err
	}
	if err := zw.Close(); err != nil {
		return nil, err
	}
	return buf.Bytes(), nil
}

package archive

import (
	"crypto/sha256"
	"database/sql"
	"encoding/hex"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path/filepath"

	"github.com/fenelon/arc5/internal/model"
)

// MediaPath is where a file with this SHA-256 (hex) is kept. Identical files
// share one path, so a forwarded photo is stored once.
func (s *Store) MediaPath(sha256hex string) string {
	return filepath.Join(s.dataDir, "media", sha256hex[:2], sha256hex[2:4], sha256hex)
}

const attachmentByRef = `
	SELECT a.id FROM attachments a
	JOIN messages m ON m.id = a.message_id
	JOIN chats c ON c.id = m.chat_id
	WHERE c.account_id = ? AND c.source_id = ? AND m.source_id = ? AND a.position = ?`

func (s *Store) attachmentID(accountID int64, ref model.AttachmentRef) (int64, error) {
	var id int64
	err := s.w.QueryRow(attachmentByRef, accountID, ref.ChatSourceID, ref.MessageSourceID, ref.Position).Scan(&id)
	if errors.Is(err, sql.ErrNoRows) {
		return 0, fmt.Errorf("%w: %+v", ErrUnknownAttachment, ref)
	}
	return id, err
}

// readTracker remembers whether a copy failed on the reading side.
type readTracker struct {
	r   io.Reader
	err error
}

func (t *readTracker) Read(p []byte) (int, error) {
	n, err := t.r.Read(p)
	if err != nil && err != io.EOF {
		t.err = err
	}
	return n, err
}

// PutMedia stores an attachment's bytes and marks it stored. The file is
// written to a temp file, synced, and renamed into place, so a failed or
// interrupted download never leaves a partial file under a content hash.
// A failure of r is reported wrapping ErrMediaRead and leaves the attachment
// as it was.
func (s *Store) PutMedia(accountID int64, ref model.AttachmentRef, r io.Reader) error {
	id, err := s.attachmentID(accountID, ref)
	if err != nil {
		return err
	}
	tmpDir := filepath.Join(s.dataDir, "media", "tmp")
	if err := os.MkdirAll(tmpDir, 0o700); err != nil {
		return err
	}
	tmp, err := os.CreateTemp(tmpDir, "put-*") // created with mode 0600
	if err != nil {
		return err
	}
	defer os.Remove(tmp.Name()) // fails harmlessly once the file has been renamed

	hash := sha256.New()
	tracked := &readTracker{r: r}
	size, err := io.Copy(io.MultiWriter(tmp, hash), tracked)
	if err == nil {
		err = tmp.Sync()
	}
	if closeErr := tmp.Close(); err == nil {
		err = closeErr
	}
	if tracked.err != nil {
		return fmt.Errorf("%w: %v", ErrMediaRead, tracked.err)
	}
	if err != nil {
		return err
	}

	sum := hex.EncodeToString(hash.Sum(nil))
	final := s.MediaPath(sum)
	if _, err := os.Stat(final); errors.Is(err, fs.ErrNotExist) {
		if err := os.MkdirAll(filepath.Dir(final), 0o700); err != nil {
			return err
		}
		if err := os.Rename(tmp.Name(), final); err != nil {
			return err
		}
	} else if err != nil {
		return err
	}

	_, err = s.w.Exec(`UPDATE attachments SET sha256 = ?, size = ?, status = 'stored', reason = '', requested = 0 WHERE id = ?`, sum, size, id)
	return err
}

// SetAttachmentStatus records why an attachment was not stored. Only skipped,
// failed and unavailable are accepted; stored is reached through PutMedia and
// pending through RequestMedia.
func (s *Store) SetAttachmentStatus(accountID int64, ref model.AttachmentRef, status model.AttachmentStatus, reason string) error {
	switch status {
	case model.StatusSkipped, model.StatusFailed, model.StatusUnavailable:
	default:
		return fmt.Errorf("%w: attachment status %q cannot be set directly", ErrInvalid, status)
	}
	id, err := s.attachmentID(accountID, ref)
	if err != nil {
		return err
	}
	_, err = s.w.Exec(`UPDATE attachments SET status = ?, reason = ?, requested = 0 WHERE id = ?`, string(status), clean(reason), id)
	return err
}

// RequestMedia queues an attachment for download regardless of the size cap,
// and returns the account and ref so the caller can notify a running connector.
// The request is stored, so it survives until a connector fulfils it.
func (s *Store) RequestMedia(attachmentID int64) (int64, model.AttachmentRef, error) {
	tx, err := s.w.Begin()
	if err != nil {
		return 0, model.AttachmentRef{}, err
	}
	defer tx.Rollback()

	res, err := tx.Exec(`UPDATE attachments SET status = 'pending', reason = '', requested = 1 WHERE id = ? AND status != 'stored'`, attachmentID)
	if err != nil {
		return 0, model.AttachmentRef{}, err
	}
	if n, err := res.RowsAffected(); err != nil {
		return 0, model.AttachmentRef{}, err
	} else if n == 0 {
		return 0, model.AttachmentRef{}, fmt.Errorf("attachment %d is missing or already stored: %w", attachmentID, ErrNotFound)
	}

	var (
		accountID int64
		ref       model.AttachmentRef
	)
	err = tx.QueryRow(`
		SELECT c.account_id, c.source_id, m.source_id, a.position FROM attachments a
		JOIN messages m ON m.id = a.message_id
		JOIN chats c ON c.id = m.chat_id
		WHERE a.id = ?`, attachmentID).Scan(&accountID, &ref.ChatSourceID, &ref.MessageSourceID, &ref.Position)
	if err != nil {
		return 0, model.AttachmentRef{}, err
	}
	return accountID, ref, tx.Commit()
}

// RequestedMedia lists an account's attachments waiting on an explicit request.
func (s *Store) RequestedMedia(accountID int64) ([]model.AttachmentRef, error) {
	rows, err := s.r.Query(`
		SELECT c.source_id, m.source_id, a.position FROM attachments a
		JOIN messages m ON m.id = a.message_id
		JOIN chats c ON c.id = m.chat_id
		WHERE a.requested = 1 AND a.status = 'pending' AND c.account_id = ?
		ORDER BY a.id`, accountID)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	var out []model.AttachmentRef
	for rows.Next() {
		var ref model.AttachmentRef
		if err := rows.Scan(&ref.ChatSourceID, &ref.MessageSourceID, &ref.Position); err != nil {
			return nil, err
		}
		out = append(out, ref)
	}
	return out, rows.Err()
}

// Package connector defines how message sources plug into arc5 and supervises
// them. A connector knows its source's protocol and nothing about storage.
package connector

import (
	"context"
	"errors"
	"io"

	"github.com/fenelon/arc5/internal/model"
)

// Connector captures one account's messages from one kind of source.
// Connectors are strictly one-way: they never send, edit or delete at the source.
type Connector interface {
	// Run performs backfill and then live capture. It blocks until ctx is
	// cancelled or an unrecoverable error occurs. Returning ErrNeedsLogin
	// stops the runner from retrying. Settings are fixed for the duration of
	// a run; the runner restarts the connector when they change.
	Run(ctx context.Context, sink Sink, state State, settings map[string]string) error

	// Setup returns the interactive flow used to connect an account.
	Setup(state State) SetupFlow

	// Settings describes the per-account options the interface should offer.
	Settings() []Field
}

// Sink is where a connector emits what it captures. All methods are safe for
// concurrent use and every write is idempotent.
type Sink interface {
	UpsertChat(model.Chat) error
	UpsertSender(model.Sender) error
	// UpsertMessage returns the attachments still to download.
	UpsertMessage(model.Message) ([]model.AttachmentRef, error)
	MarkDeleted(chatSourceID string, messageSourceIDs []string) error
	// LookupChats finds which chats hold a message, for sources that report
	// deletions without naming the chat.
	LookupChats(messageSourceID string, kinds []model.ChatKind) ([]string, error)
	PutMedia(ref model.AttachmentRef, r io.Reader) error
	SetAttachmentStatus(ref model.AttachmentRef, status model.AttachmentStatus, reason string) error
	ChatArchived(chatSourceID string) (bool, error)
	// RequestedMedia delivers attachments the owner asked to fetch or retry.
	// They are downloaded regardless of the size cap. A ref may be delivered
	// more than once.
	RequestedMedia() <-chan model.AttachmentRef
	ReportProgress(Progress)
}

// State is a connector's private per-account key-value store, for sessions and checkpoints.
type State interface {
	// Get returns nil when the key is unset.
	Get(key string) ([]byte, error)
	Set(key string, value []byte) error
}

// SetupFlow walks the owner through connecting an account.
type SetupFlow interface {
	// Next submits the previous step's input (nil for the first call) and
	// returns the next step. A step with Done set ends the flow.
	Next(ctx context.Context, input map[string]string) (Step, error)
}

type Step struct {
	Title  string
	Help   string
	Fields []Field
	Done   bool
}

type FieldKind string

const (
	FieldText   FieldKind = "text"
	FieldSecret FieldKind = "secret"
	FieldNumber FieldKind = "number"
	FieldChoice FieldKind = "choice"
)

type Field struct {
	Name    string
	Label   string
	Help    string
	Kind    FieldKind
	Choices []string // for FieldChoice
	Default string
}

type Phase string

const (
	PhaseConnecting  Phase = "connecting"
	PhaseBackfill    Phase = "backfill"
	PhaseLive        Phase = "live"
	PhaseRateLimited Phase = "rate_limited"
)

// Progress is a connector's latest report of what it is doing.
type Progress struct {
	Phase      Phase
	Detail     string
	ChatsDone  int
	ChatsTotal int
}

var (
	// ErrNeedsLogin means the account's session is missing or revoked. The
	// runner stops retrying until the owner logs in again.
	ErrNeedsLogin = errors.New("account needs login")
	// ErrStorage wraps archive failures a connector cannot fix, such as a full disk.
	ErrStorage = errors.New("archive storage failed")
)

package connector

import (
	"sort"
	"sync"
)

// Factory builds a fresh connector for one run.
type Factory func() Connector

// Registry maps connector names to factories.
type Registry struct {
	mu        sync.RWMutex
	factories map[string]Factory
}

// Default is the registry connector packages add themselves to.
var Default = NewRegistry()

func NewRegistry() *Registry {
	return &Registry{factories: map[string]Factory{}}
}

// Register adds a connector. It panics on an empty or duplicate name, since
// both are programming errors caught at startup.
func (r *Registry) Register(name string, f Factory) {
	r.mu.Lock()
	defer r.mu.Unlock()
	if name == "" {
		panic("connector: empty name")
	}
	if _, dup := r.factories[name]; dup {
		panic("connector: " + name + " registered twice")
	}
	r.factories[name] = f
}

func (r *Registry) New(name string) (Connector, bool) {
	r.mu.RLock()
	f, ok := r.factories[name]
	r.mu.RUnlock()
	if !ok {
		return nil, false
	}
	return f(), true
}

func (r *Registry) Names() []string {
	r.mu.RLock()
	defer r.mu.RUnlock()
	names := make([]string, 0, len(r.factories))
	for name := range r.factories {
		names = append(names, name)
	}
	sort.Strings(names)
	return names
}

// accountSink binds the archive to one account.

	store     *archive.Store
	accountID int64
	requests  <-chan model.AttachmentRef
	progress  func(Progress)
}

func newSink(store *archive.Store, accountID int64, requests <-chan model.AttachmentRef, progress func(Progress)) Sink {
	return &accountSink{store: store, accountID: accountID, requests: requests, progress: progress}
}

// classify marks archive failures the connector cannot fix as ErrStorage and
// passes through the ones that describe the connector's own input.
func classify(err error) error {
	switch {
	case err == nil:
		return nil
	case errors.Is(err, archive.ErrUnknownChat),
		errors.Is(err, archive.ErrUnknownAttachment),
		errors.Is(err, archive.ErrMediaRead),
		errors.Is(err, archive.ErrInvalid):
		return err
	default:
		return fmt.Errorf("%w: %v", ErrStorage, err)
	}
}

func (s *accountSink) UpsertChat(c model.Chat) error {
	return classify(s.store.UpsertChat(s.accountID, c))
}

func (s *accountSink) UpsertSender(sn model.Sender) error {
	return classify(s.store.UpsertSender(s.accountID, sn))
}

func (s *accountSink) UpsertMessage(m model.Message) ([]model.AttachmentRef, error) {
	refs, err := s.store.UpsertMessage(s.accountID, m)
	return refs, classify(err)
}

func (s *accountSink) MarkDeleted(chatSourceID string, messageSourceIDs []string) error {
	return classify(s.store.MarkDeleted(s.accountID, chatSourceID, messageSourceIDs))
}

func (s *accountSink) LookupChats(messageSourceID string, kinds []model.ChatKind) ([]string, error) {
	chats, err := s.store.LookupChats(s.accountID, messageSourceID, kinds)
	return chats, classify(err)
}

	return classify(s.store.PutMedia(s.accountID, ref, r))
}

func (s *accountSink) SetAttachmentStatus(ref model.AttachmentRef, status model.AttachmentStatus, reason string) error {
	return classify(s.store.SetAttachmentStatus(s.accountID, ref, status, reason))
}

	archived, err := s.store.ChatArchived(s.accountID, chatSourceID)

	LastError string
	Progress  Progress
}

const (
	maxBackoff = 5 * time.Minute
	// A run that lasted this long counts as healthy and resets the backoff.
	healthyRun = time.Minute
	// Room for requests made while a connector is busy.
	requestBuffer = 256
)

// DefaultBackoff waits one second after the first failure and doubles up to five minutes.
func DefaultBackoff(attempt int) time.Duration {
	if attempt < 1 {
		attempt = 1
	}
	if attempt > 9 { // 1s << 9 is already past the cap
		return maxBackoff
	}
	return time.Second << (attempt - 1)
}

var errUnknownConnector = errors.New("no such connector")

// Runner supervises one connector per enabled account.
type Runner struct {
	store *archive.Store
	reg   *Registry
	// Backoff returns how long to wait before retry number attempt (from 1).
	Backoff func(attempt int) time.Duration
	now     func() time.Time

	mu       sync.Mutex
	ctx      context.Context
	accounts map[int64]*supervised
}

type supervised struct {
	cancel   context.CancelFunc
	done     chan struct{}
	status   Status
	requests chan model.AttachmentRef
}

func NewRunner(store *archive.Store, reg *Registry) *Runner {
	return &Runner{
		store:    store,
		reg:      reg,
		Backoff:  DefaultBackoff,
		now:      time.Now,
		ctx:      context.Background(),
		accounts: map[int64]*supervised{},
	}
}

// Start launches a connector for every enabled account. Connectors stop when
// ctx is cancelled; call Wait afterwards to let them finish.
func (r *Runner) Start(ctx context.Context) error {
	accounts, err := r.store.Accounts()
	if err != nil {
		return err
	}
	r.mu.Lock()
	r.ctx = ctx
	r.mu.Unlock()
	for _, acc := range accounts {
		if acc.Enabled {
			r.launch(acc)
		}
	}
	return nil
}

func (r *Runner) launch(acc archive.Account) {
	r.mu.Lock()
	ctx, cancel := context.WithCancel(r.ctx)
	s := &supervised{
		cancel: cancel,
		done:   make(chan struct{}),
		status: Status{AccountID: acc.ID, Connector: acc.Connector, Label: acc.Label, State: StateStopped, Since: r.now()},
	}
	r.accounts[acc.ID] = s
	r.mu.Unlock()
	go r.supervise(ctx, acc, s)
}

// Restart stops an account's connector, reloads the account, and starts it
// again if it is enabled. Call it after changing an account's settings or a
// chat's archive toggle; checkpoints make the restart lossless.
func (r *Runner) Restart(accountID int64) error {
	r.mu.Lock()
	s := r.accounts[accountID]
	delete(r.accounts, accountID)
	r.mu.Unlock()
	if s != nil {
		s.cancel()
		<-s.done
	}
	acc, err := r.store.Account(accountID)
	if err != nil {
		return err
	}
	if acc.Enabled {
		r.launch(acc)
	}
	return nil
}

// Wait blocks until every supervised connector has stopped.
func (r *Runner) Wait() {
	r.mu.Lock()
	all := make([]*supervised, 0, len(r.accounts))
	for _, s := range r.accounts {
		all = append(all, s)
	}
	r.mu.Unlock()
	for _, s := range all {
		<-s.done
	}
}

func (r *Runner) Status() []Status {
	r.mu.Lock()
	out := make([]Status, 0, len(r.accounts))
	for _, s := range r.accounts {
		out = append(out, s.status)
	}
	r.mu.Unlock()
	sort.Slice(out, func(i, j int) bool { return out[i].AccountID < out[j].AccountID })
	return out
}

// RequestMedia asks for an attachment to be downloaded regardless of the size
// cap. The request is stored first, so it is delivered when the connector next
// starts if it cannot be handed over now.
func (r *Runner) RequestMedia(attachmentID int64) error {
	accountID, ref, err := r.store.RequestMedia(attachmentID)
	if err != nil {
		return err
	}
	r.mu.Lock()
	defer r.mu.Unlock()
	if s := r.accounts[accountID]; s != nil && s.requests != nil {
		select {
		case s.requests <- ref:
		default: // full; the stored request is picked up on the next start
		}
	}
	return nil
}

func (r *Runner) update(s *supervised, change func(*Status)) {
	r.mu.Lock()
	change(&s.status)
	r.mu.Unlock()
}

func (r *Runner) setState(s *supervised, state RunState, lastError string) {
	now := r.now()
	r.update(s, func(st *Status) {
		st.State, st.Since, st.LastError = state, now, lastError
	})
}

func (r *Runner) supervise(ctx context.Context, acc archive.Account, s *supervised) {
	defer close(s.done)
	attempt := 0
	for {
		started := r.now()
		err := r.runOnce(ctx, acc, s)
		switch {
		case ctx.Err() != nil:
			r.setState(s, StateStopped, "")
			return
		case errors.Is(err, errUnknownConnector):
			r.setState(s, StateStopped, err.Error())
			return
		case errors.Is(err, ErrNeedsLogin):
			r.setState(s, StateNeedsLogin, err.Error())
			return
		}

		next := StateBackoff
		if errors.Is(err, ErrStorage) {
			next = StatePaused
		}
		if r.now().Sub(started) >= healthyRun {
			attempt = 0
		}
		attempt++
		r.setState(s, next, err.Error())

		timer := time.NewTimer(r.Backoff(attempt))
		select {
		case <-ctx.Done():
			timer.Stop()
			r.setState(s, StateStopped, "")
			return
		case <-timer.C:
		}
	}
}

// runOnce runs the connector until it returns. It always returns a non-nil
// error unless ctx was cancelled, and turns a panic into an error.
func (r *Runner) runOnce(ctx context.Context, acc archive.Account, s *supervised) (err error) {
	c, ok := r.reg.New(acc.Connector)
	if !ok {
		return fmt.Errorf("%w: %q", errUnknownConnector, acc.Connector)
	}

	pending, err := r.store.RequestedMedia(acc.ID)
	if err != nil {
		return fmt.Errorf("%w: %v", ErrStorage, err)
	}
	requests := make(chan model.AttachmentRef, len(pending)+requestBuffer)
	for _, ref := range pending {
		requests <- ref
	}
	r.mu.Lock()
	s.requests = requests
	r.mu.Unlock()

	sink := newSink(r.store, acc.ID, requests, func(p Progress) {
		r.update(s, func(st *Status) { st.Progress = p })
	})
	now := r.now()
	r.update(s, func(st *Status) {
		st.State, st.Since, st.LastError, st.Progress = StateRunning, now, "", Progress{}
	})

	defer func() {
		if p := recover(); p != nil {
			err = fmt.Errorf("connector panicked: %v", p)
		}
	}()
	err = c.Run(ctx, sink, accountState{store: r.store, accountID: acc.ID}, acc.Settings)
	if err == nil {
		err = errors.New("connector stopped without an error")
	}
	return err
}

// ingest path without a real message source.
package connectortest

import (
	"bytes"
	"context"
	"sync"

	"github.com/fenelon/arc5/internal/connector"
	"github.com/fenelon/arc5/internal/model"
)

// Step is one thing the fake connector does to its sink.
type Step func(sink connector.Sink) error

// Fake applies its steps in order each time it is run, then idles until cancelled.
type Fake struct {
	steps []Step
	once  sync.Once
	done  chan struct{}
	err   error
}

func New(steps ...Step) *Fake {
	return &Fake{steps: steps, done: make(chan struct{})}
}

// Done is closed when the first run has applied every step or hit an error.
func (f *Fake) Done() <-chan struct{} { return f.done }

// Err is the first run's step error, if any. Read it only after Done is closed.
func (f *Fake) Err() error { return f.err }

func (f *Fake) Run(ctx context.Context, sink connector.Sink, _ connector.State, _ map[string]string) error {
	var err error
	for _, step := range f.steps {
		if err = step(sink); err != nil {
			break
		}
	}
	f.once.Do(func() {
		f.err = err
		close(f.done)
	})
	<-ctx.Done()
	return ctx.Err()
}

func (f *Fake) Setup(connector.State) connector.SetupFlow { return nil }
func (f *Fake) Settings() []connector.Field               { return nil }

func Chat(c model.Chat) Step {
	return func(sink connector.Sink) error { return sink.UpsertChat(c) }
}

func Sender(s model.Sender) Step {
	return func(sink connector.Sink) error { return sink.UpsertSender(s) }
}

func Message(m model.Message) Step {
	return func(sink connector.Sink) error {
		_, err := sink.UpsertMessage(m)
		return err
	}
}

// Delete reports a deletion the way a source that names the chat does.
func Delete(chatSourceID string, ids ...string) Step {
	return func(sink connector.Sink) error { return sink.MarkDeleted(chatSourceID, ids) }
}

// DeleteWithoutChat reports a deletion the way a source that gives only
// message IDs does: the connector looks the chat up first.
func DeleteWithoutChat(kinds []model.ChatKind, ids ...string) Step {
	return func(sink connector.Sink) error {
		for _, id := range ids {
			chats, err := sink.LookupChats(id, kinds)
			if err != nil {
				return err
			}
			for _, chat := range chats {
				if err := sink.MarkDeleted(chat, []string{id}); err != nil {
					return err
				}
			}
		}
		return nil
	}
}

func Media(ref model.AttachmentRef, content []byte) Step {
	return func(sink connector.Sink) error { return sink.PutMedia(ref, bytes.NewReader(content)) }
}

// Package config reads the few settings that cannot live in the database.
package config

import (
	"flag"
	"fmt"
	"io"
)

type Config struct {
	Listen  string
	DataDir string
}

// Parse reads `serve` arguments. Flags win over environment variables, which
// win over defaults.
func Parse(args []string, getenv func(string) string) (Config, error) {
	cfg := Config{Listen: "127.0.0.1:8080", DataDir: "data"}
	if v := getenv("ARC5_LISTEN"); v != "" {
		cfg.Listen = v
	}
	if v := getenv("ARC5_DATA"); v != "" {
		cfg.DataDir = v
	}

	fs := flag.NewFlagSet("serve", flag.ContinueOnError)
	fs.SetOutput(io.Discard)
	fs.StringVar(&cfg.Listen, "listen", cfg.Listen, "address to listen on (ARC5_LISTEN)")
	fs.StringVar(&cfg.DataDir, "data", cfg.DataDir, "data folder (ARC5_DATA)")
	if err := fs.Parse(args); err != nil {
		return Config{}, err
	}
	if fs.NArg() > 0 {
		return Config{}, fmt.Errorf("unexpected argument %q", fs.Arg(0))
	}
	return cfg, nil
}

package web

import (
	"io"
	"net/http"
)

// NewHandler returns the HTTP handler. /healthz is unauthenticated and
// deliberately says nothing about accounts.
func NewHandler() http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /healthz", func(w http.ResponseWriter, _ *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		io.WriteString(w, `{"status":"ok"}`+"\n")
	})
	return mux
}

// Command arc5 is a self-hosted message archive.
package main

import (
	"context"
	"errors"
	"fmt"
	"log"
	"net"
	"net/http"
	"os"
	"os/signal"
	"syscall"
	"time"

	"github.com/fenelon/arc5/internal/archive"
	"github.com/fenelon/arc5/internal/config"
	"github.com/fenelon/arc5/internal/connector"
	"github.com/fenelon/arc5/internal/web"
)

const usage = "usage: arc5 serve [--listen address] [--data folder]"

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()
	if err := run(ctx, os.Args[1:], os.Getenv, nil); err != nil {
		fmt.Fprintln(os.Stderr, "arc5:", err)
		os.Exit(1)
	}
}

// run executes one command. ready, if set, is called with the listening
// address once the server accepts connections.
func run(ctx context.Context, args []string, getenv func(string) string, ready func(addr string)) error {
	if len(args) == 0 {
		return errors.New(usage)
	}
	switch args[0] {
	case "serve":
		cfg, err := config.Parse(args[1:], getenv)
		if err != nil {
			return fmt.Errorf("%w\n%s", err, usage)
		}
		return serve(ctx, cfg, ready)
	default:
		return fmt.Errorf("unknown command %q\n%s", args[0], usage)
	}
}

func serve(ctx context.Context, cfg config.Config, ready func(addr string)) error {
	store, err := archive.Open(cfg.DataDir)
	if err != nil {
		return err
	}
	defer store.Close()

	ln, err := net.Listen("tcp", cfg.Listen)
	if err != nil {
		return fmt.Errorf("listen on %s: %w", cfg.Listen, err)
	}

	// Connectors stop before the store closes, whichever way serve returns.
	ctx, cancel := context.WithCancel(ctx)
	runner := connector.NewRunner(store, connector.Default)
	defer func() {
		cancel()
		runner.Wait()
	}()
	if err := runner.Start(ctx); err != nil {
		ln.Close()
		return err
	}

	srv := &http.Server{Handler: web.NewHandler(), ReadHeaderTimeout: 10 * time.Second}
	served := make(chan error, 1)
	go func() { served <- srv.Serve(ln) }()
	log.Printf("arc5 listening on http://%s, data in %s", ln.Addr(), cfg.DataDir)
	if ready != nil {
		ready(ln.Addr().String())
	}

	select {
	case err := <-served:
		return err
	case <-ctx.Done():
	}
	shutdownCtx, cancelShutdown := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancelShutdown()
	return srv.Shutdown(shutdownCtx)
}
```

# arc5

A self-hosted archive for your message history. It keeps a durable, searchable
copy of your chats so you can clean out accounts or use auto-delete without
losing anything.

**Status:** early development. The archive core runs; search, the web
interface and the Telegram connector are not built yet. The design is in
[`docs/superpowers/specs`](docs/superpowers/specs).

## Run

```bash
go build -o arc5 ./cmd/arc5
./arc5 serve --data ./data
```

| Flag | Environment | Default | Meaning |
|---|---|---|---|
| `--listen` | `ARC5_LISTEN` | `127.0.0.1:8080` | Address to listen on |
| `--data` | `ARC5_DATA` | `data` | Folder for the database and media |

`GET /healthz` answers `{"status":"ok"}`.

The data folder holds everything arc5 knows, including connector sessions that
grant full access to your accounts. It is created with mode `0700`; keep it
that way.
